# CoAff-DTI

CoAff-DTI is an end-to-end deep learning framework for fine-grained drug--target interaction (DTI) prediction using pre-trained language models (PLMs) and affinity-guided cross-modal interaction learning.


---


# Environment Setup

## Requirements

- Python 3.9
- PyTorch 2.1.1
- CUDA 12.1
